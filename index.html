CHOICE — CONDITIONS

Programs can make decisions using conditions. 

hp = 20

if hp > 0:
    print("You are still standing.")
else:
    print("Game Over.")

Python uses indentation to determine which code belongs inside a condition.

ENDLESS CORRIDOR — LOOPS

For Loop

for i in range(5):
    print("You moved.")

While Loop

hp = 3

while hp > 0:
    print("Still alive.")
    hp -= 1

SPECIAL ATTACK — FUNCTIONS

Functions let you create reusable pieces of code. 

def greet(name):

    return "Hello, " + name


message = greet("Player")

print(message)

INVENTORY — LISTS
